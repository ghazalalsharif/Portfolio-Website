## About this website

A responsive static portfolio that brings together project screenshots, source links, courses, bootcamp certificates and volunteering. Built with HTML, CSS and vanilla JavaScript; hosted on GitHub Pages.

- Mobile navigation and keyboard focus support
- Reduced-motion support
- Real project previews and downloadable certificates
- Clear distinction between project experience and coursework

## Run locally

Download or clone this repository and open `index.html` in a browser. No package installation or build step is required. An internet connection is needed for Google Fonts and external links.

## File guide

- `index.html` — page content and project links
- `styles.css` — layout, visual design and responsive navigation
- `main.js` — navigation and scroll interactions
- `certificates.css` — course and certificate layouts
- `project-previews.css` — project screenshot styles
- `assets/projects/` — application screenshots
- `assets/certificates/` — certificate documents
